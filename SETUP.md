# Put the arcade on your GitHub profile

Copy `README.md` and the entire `assets` folder into the root of your public **TobilobaLucas/TobilobaLucas** repository. Commit both together. The relative image paths then work without changing a branch name or hosting anything elsewhere.

GitHub documents the profile repository requirements [here](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme).

The cover is an animated GIF. A static SVG is selected for visitors who request reduced motion through their browser or operating system. The original vector cover is also included for easy editing. All artwork is local; the profile needs no image widget service, API token, cron job, or external font.

The boss fights use GitHub's native expandable sections, including a second reveal inside each encounter. See [GitHub's collapsed section documentation](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/organizing-information-with-collapsed-sections). The portfolio, project, email, and social links are real links from the supplied profile. Project status is descriptive; there is no pretend live telemetry.

## Edit the artwork

Requires Node.js and Sharp (the version is pinned in `package.json`):

```sh
npm install
npm run build
npm test
```

The assets are generated by `scripts/build.mjs`. Change the text, palette, or drawings there and rebuild. Rendering uses system fonts with common fallbacks. Font metrics can vary on another operating system; inspect the result after rebuilding.

## Preview

```sh
npm run preview
```

Open <http://127.0.0.1:4187>. The preview renders the actual README with a small Markdown renderer and a GitHub-like stylesheet; it is an approximation, not GitHub's own renderer. It includes a reduced-motion toggle and a light/dark toggle for checking the artwork and content. The finished profile itself uses only Markdown, HTML supported by GitHub, and images. Set the `PORT` environment variable to use a different port.

Only `README.md` and `assets/` are needed on your profile. The generator, preview, and setup notes are optional authoring tools.
